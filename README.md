# PTE Core 学习资料

这里整理了 PTE Core 多种题型的题目、作答框架与参考答案，便于复习和练习。Describe Image 文档附有题目原图，请保留图片目录结构以正常显示。

> 参考答案用于练习和学习表达；请结合官方考试要求与自己的练习情况使用。
